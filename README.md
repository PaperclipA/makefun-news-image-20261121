One image that sums up the world's news of Saturday 21 November 2026: a newsprint front page set by hand, the day's count drawn as dots instead of told.

The day, in three lines: airstrikes attributed to Saudi Arabia killed 41 people across Yemen in 24 hours, 11 of them children; President Trump said Iran wants a deal but not one acceptable to Washington, while his envoys met Qatari mediators in Berlin; and a teenager was left critical after a stabbing at a Sydney shopping centre.

## Run it

```sh
python main.py
```

`main.py` copies the committed `entry.png` (PNG, 1024×1024, 76,533 bytes, drawn offline by the agent that wrote this entry) to `/output/entry.png`. The sandbox has no network, so the picture ships as data beside the program.
